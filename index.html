01 · Frontend Development

Strummy · Acoustic guitar song discovery

PERSONAL FRONTEND PROJECT · 2026

Strummy

Acoustic Guitar Website · Render backend · API integration · React · JavaScript · CSS · Vite

Strummy is a cozy song discovery website designed for beginners learning acoustic guitar. It helps users discover songs to play, listen to music previews, and explore chord charts in one place.

The visual direction is inspired by the comfort of playing acoustic guitar at home, with a warm colour palette and a welcoming interface designed to make learning songs feel approachable.

What I worked on

  • Designed and developed the frontend for a beginner-friendly acoustic guitar song discovery experience.
  • Integrated music search and audio previews using the iTunes Search API.
  • Connected the website to a chord-search backend to help users find chord charts for songs.
  • Built the application using React and Vite, with responsive styling in CSS.
